# mTunes（Androidナビ用 音楽プレーヤー）

USBメモリ内の音楽を、CarPlayの「ミュージック」に近い操作感で再生するAndroidアプリです。
対象：Android 10以上（PR-JM200 / Android 14 / 11.8インチ横長画面で使う想定）

## できること
- 画面左のサイドバー：再生中／アーティスト／アルバム／曲／検索／設定
- 曲名・アーティスト・アルバム・曲順・年・アルバムアートはすべて IDタグ から取得
  - アルバム内は「ディスク番号 → トラック番号」順、複数ディスクは見出し付き
  - アルバムアーティストのタグがあればそれでまとめ、無ければアーティスト名でまとめる
  - アートワークは埋め込み画像 → フォルダ内の cover.jpg / folder.jpg 等 → Androidのサムネイルの順に探す
- アーティスト・曲一覧の右端に索引（A〜Z、あ・か・さ…わ、漢字、#）。タップ・なぞりでジャンプ
  - 先頭の "The " は無視、全角/半角・カタカナ/ひらがなは同一視して並べる
- アーティスト画面：再生／シャッフル、アルバム一覧（年順）
- 再生中画面：大きなアートワーク、シーク、前/再生/次、シャッフル、リピート（全曲/1曲）、次に再生リスト
- 前の曲ボタン：3秒以上再生中なら曲の頭へ、それ以外は前の曲へ（CarPlayと同じ動き）
- ハンドルのリモコンボタン・通知からも操作可能（MediaSession対応）
- 再生キューと再生位置を保存し、次回アプリを開くと続きから自動再生（設定でオフ可）
- USBを挿すと自動でライブラリ更新
- 曲が出ない機種向けに「フォルダを指定して直接読み込む」モード

## ビルド方法（パソコンで行う場合）
1. Android Studio（最新版）をインストールして起動
2. 「Open」でこの `UsbMusic` フォルダを開く（初回は必要な部品のダウンロードに数分〜十数分）
3. メニュー Build → Generate App Bundles or APKs → Build APK(s)
   - 動作が軽いリリース版を作る場合は、画面下のターミナルで `./gradlew assembleRelease`（Windowsは `gradlew.bat assembleRelease`）
4. できたAPK
   - デバッグ版：`app/build/outputs/apk/debug/app-debug.apk`
   - リリース版：`app/build/outputs/apk/release/app-release.apk`（おすすめ）

## ナビへのインストール
1. APKをUSBメモリにコピー
2. ナビのファイルマネージャーでAPKを開く
3. 「提供元不明のアプリ」の許可を求められたら許可してインストール
4. 初回起動時に「音楽とオーディオへのアクセス」と「通知」を許可

## 補足
- 個人利用向けにデバッグ用の鍵で署名しています（ストア公開はしない前提）
- IDタグの文字化け（古いShift_JISのID3v1タグなど）はAndroidの読み取り仕様に依存します
